# 💛 Happy Yellow Flowers Day - 21 de Septiembre 🌻

## Características
- 🌻 Temática de Flores Amarillas
- ☀️ Fondo degradado dinámico con sol animado
- 🌸 Flores CSS animadas con pétalos realistas
- ✨ Partículas flotantes de pétalos dorados
- 🎮 Interacciones: haz clic para plantar flores, botón brincador
- 🎉 Efecto de celebración con destellos animados
- 📱 Diseño responsive y minimalista

## Cómo funciona
Página dedicada al **Día de las Flores Amarillas** (21 de Septiembre) con un diseño elegante, moderno y minimalista. Disfruta de flores animadas, partículas doradas flotantes y animaciones suaves.

## Estructura del proyecto
- `index.html` — Página principal de celebración
- `yay.html` — Página de agradecimiento
- `styles.css` — Estilos con paleta amarilla/dorada
- `script.js` — Interacciones y partículas
- `other.js` — Funcionalidad del botón brincador

## Clona este proyecto
```bash
git clone https://github.com/DarwinTQ/valentinMod
```
Abre `index.html` en tu navegador.

## ¡Celebra el 21 de Septiembre con flores amarillas! 🌻💛
